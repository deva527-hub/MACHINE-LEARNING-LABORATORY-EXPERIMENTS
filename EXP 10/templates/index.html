How to Compile & Run the Code

1. Install Dependencies

Open PowerShell or Terminal in the project directory:

pip install -r requirements.txt

2. Run the Web Application

Launch the interactive single-frame web server:

python app.py

Then open your browser at: http://127.0.0.1:5000

3. Run / Compile via Command-Line Interface (CLI)

Train classifiers and diagnose images straight from the terminal:

# 1. Generate sample medical images:
python train_cli.py --generate-data
# 2. Train and evaluate SVM classifier:
python train_cli.py --train --algo svm
# 3. Train Random Forest model:
python train_cli.py --train --algo random_forest
# 4. Predict diagnosis on any image file:
python train_cli.py --predict static/samples/pneumonia/pneumonia_case_01.jpg

4. Pipeline Architecture

  • Load Input Image: Ingests radiological images, extracts intensity histogram and dimensions.
  • Preprocessor: Grayscale conversion, 128x128 resizing, 3x3 median denoising, histogram equalization, and [0,1] normalization.
  • Feature Extraction: 13 clinical descriptors (Haralick GLCM contrast, homogeneity, energy, correlation + statistical moments + Sobel edge energy).
  • Training: SVM, Random Forest, KNN, Logistic Regression with stratified split.
  • Evaluation: Confusion matrix (TP/FP/TN/FN), Sensitivity (Recall), Specificity, Precision, F1-Score, and ROC-AUC.
